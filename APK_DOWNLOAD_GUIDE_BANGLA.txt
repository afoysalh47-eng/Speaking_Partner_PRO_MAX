কেন "Download ZIP"-এর ভেতরে সরাসরি .apk ফাইল থাকে না?
----------------------------------------------------------------------
Google AI Studio-তে "Export -> Download ZIP" বাটনে ক্লিক করলে শুধুমাত্র প্রজেক্টের
Source Code (কোড ফাইলগুলো) জিপ আকারে ডাউনলোড হয়। সিকিউরিটি ও সাইজের কারণে
AI Studio সোর্স কোড জিপের ভেতরে বাইনারি .apk ফাইল অন্তর্ভুক্ত করে না।

আপনি যেভাবে সরাসরি ইনস্টলযোগ্য .apk ফাইল পাবেন:
----------------------------------------------------------------------

পদ্ধতি ১: AI Studio থেকে সরাসরি APK জেনারেট (সবচেয়ে সহজ)
১. কোড ভিউয়ের বাম পাশের উপরে চোখের আইকন (👁 Preview)-এ ক্লিক করে অ্যাপের প্রিভিউতে যান।
২. অথবা উপরের ডান কোণায় থাকা Settings (⚙️ গিয়ার আইকন, Publish বাটনের ডান পাশে) বা
   Export মেনুতে গিয়ে "Generate APK / Build APK" অপশনটি ব্যবহার করুন।

পদ্ধতি ২: পিসিতে কোনো সফটওয়্যার ছাড়াই GitHub থেকে ফ্রি APK ডাউনলোড
১. আমরা প্রজেক্টে অটোমেটিক ক্লাউড বিল্ডার (.github/workflows/build-apk.yml) যুক্ত করে দিয়েছি।
২. AI Studio-র "Export ⌄" বাটনে ক্লিক করে "Push to GitHub" সিলেক্ট করুন।
৩. আপনার GitHub রিপোজিটরির "Actions" ট্যাবে গেলেই ১ মিনিটের মধ্যে তৈরি হওয়া
   "Speaking_Partner_PRO_MAX_APK" সরাসরি ডাউনলোড করতে পারবেন!

পদ্ধতি ৩: পিসিতে ডাউনলোড করা ZIP ফাইল থেকে (Windows)
১. ZIP ফাইলটি Extract করুন।
২. ভেতরে থাকা "BUILD_APK_ON_WINDOWS.bat" ফাইলটিতে ডাবল-ক্লিক করুন (অথবা ফোল্ডারটি
   Android Studio-তে ওপেন করে Build -> Build APK(s) ক্লিক করুন)।
